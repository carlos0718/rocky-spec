Después de mergear a la rama principal: listar `git branch --merged development` (menos `development`/`main`). Con la política `branch_delete: auto` normalmente no queda ninguna — cada rama se borró al mergearse (ver "Branching" arriba); si queda alguna, borrarla sin preguntar con `git branch -d` (local) y `git push origin --delete` (remoto). Una rama que no esté 100% mergeada nunca se borra sin `AskUserQuestion`.
